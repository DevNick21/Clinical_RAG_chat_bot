"The real product problem is not only that clinical records are long. It is that EHR systems have a high barrier to entry: users need to know where to look, what fields mean, and how to connect evidence across sections. This project reduces that barrier by letting the user ask in natural language. Retrieval happens first, then the generated answer is grounded with citations."
