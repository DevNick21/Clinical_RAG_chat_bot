# Clinical RAG V1/V2 Reveal.js Deck

Static Reveal.js deck for the RealityMine presentation.

## Run

```powershell
cd presentations\clinical-rag-v1-v2
python -m http.server 8090
```

Then open:

```text
http://localhost:8090
```

## Present

- Speaker notes: press `S`
- Overview: press `Esc`
- Export to PDF: open `http://localhost:8090/?print-pdf`, then print to PDF
- 3D slides: move the pointer over the scene for a subtle rotation
- Heatmap slide: hover or click model cells to update the selected model pair

## Files

- `index.html` - Reveal.js slide deck
- `styles.css` - custom visual theme
- `talking-points.md` - rehearsal notes and likely interview questions

The RealityMine-style logo mark is hand-recreated as an inline SVG for presentation use; it is not an official asset file.
